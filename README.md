# CoinFlip

A lightweight GUI-based CoinFlip plugin for Paper servers with Vault economy integration.

Players can create CoinFlips, choose a wager, challenge other players and let the plugin automatically handle wagers, payouts and refunds.

## Features

- 🎲 GUI-based CoinFlip system
- 💰 Vault economy support
- ➕ Simple wager selection
- 👥 Player-vs-player CoinFlips
- 🔄 Live CoinFlip queue
- 🎬 Animated CoinFlip sequence
- 🟢 Winner GUI
- 🔴 Loser GUI
- 🔊 Sound effects
- 💸 Automatic wager withdrawal and payout
- ↩️ Queue refund system
- 🚪 Disconnect protection
- 🛑 Server shutdown refund protection
- 🔒 Protection against duplicate/invalid CoinFlips

## Requirements

Before installing CoinFlip, your server needs:

- **Paper**
- **Vault**
- **A Vault-compatible economy plugin**

CoinFlip uses Vault as its economy bridge, so an economy provider is required.
